**Один экран. Ноль промежуточных шагов.** Пользователь вводит текст / диктует / прикрепляет файл → AI раскладывает по колонкам → строки **сразу появляются в таблице** в режиме редактирования (✓ сохранить / ✗ удалить). Никаких отдельных экранов, превью-карточек или форм подтверждения.

## 1. Цель и результат

Инструмент BL-6 **заполняет реестр поручений** в Google Sheets по шаблону PMI Action Item Tracker с минимальным усилием пользователя.

**Весь функционал — на одном экране:**

- **Smart-input** (верхняя часть) — одно текстовое поле с кнопками 🎤 📎 ➤.
- **Таблица реестра** (основная часть) — read-only данные из Google Sheet с Excel-стиль фильтрами в заголовках колонок (▾).
- **Новые строки в edit-mode** — после ввода текста / загрузки файла AI раскладывает данные по колонкам, строки появляются прямо в таблице с подсветкой и кнопками ✓ (сохранить) / ✗ (удалить).

**Три способа ввода через одно поле:**

1. **Текст** — пользователь описывает поручение свободным текстом → LLM парсит → строка в таблице (edit-mode).
2. **Голос** 🎤 — диктовка через микрофон → speech-to-text → LLM парсит → строка в таблице.
3. **Файл** 📎 — протокол или запись совещания (аудио/видео) → STT + LLM → **несколько строк** в таблице (edit-mode).

**Убийственный сценарий:** пользователь прикрепляет запись летучки → через минуту в таблице появляются N строк поручений в edit-mode → пользователь проверяет, жмёт ✓ на каждой → строки сохраняются в Google Sheet.

**Принцип:** инструмент **не заменяет** Google Sheets. Таблица в AI PMO — это зеркало Google Sheet для чтения + точка входа для AI-заполнения. Редактирование существующих записей — через Google Sheets (ссылка в сайдбаре).

## 5. Объём MVP (v2.2)

### 5.1 Обязательно в MVP

1. **Авто-создание реестра:** при первом запуске создаётся чистая Google-таблица по шаблону PMI. Пользователь сразу попадает на рабочий экран. Опционально — подключение своей таблицы через сайдбар (при подключении автосозданная удаляется).
2. **Единый экран:** smart-input (текст 🎤 📎) сверху + таблица реестра снизу. Один экран для всех действий.
3. **Smart-input → direct-to-table:** свободный текст / диктовка → LLM раскладывает по колонкам PMI → новая строка **сразу появляется в таблице** в edit-mode (подсветка, все поля редактируемы, кнопки ✓ сохранить / ✗ удалить). Без промежуточных экранов.
4. **AI-инжест файлов → direct-to-table:** аудио/видео (📎) → STT + LLM → **несколько строк** появляются в таблице в edit-mode. Каждая строка — отдельное поручение с ✓ / ✗. Без отдельного экрана подтверждения.
5. **Таблица реестра с Excel-стиль фильтрами:** данные из Google Sheet; фильтрация через ▾ в заголовках колонок (как в Excel/Sheets); сортировка по клику на заголовок.
6. **Сайдбар:** навигация, «Открыть в Google Sheets ↗», «Подключить свой реестр» (опц.), настройки.
7. **Telegram-инжест (BL2-2):** текст/голос/видео боту → тот же pipeline → строки появляются в таблице.

### 5.2 Вне MVP (бэклог)

- Напоминания в Telegram по `Target Date`.
- Автоматический мониторинг просроченных поручений.
- Интеграция с Notion, Jira, Trello.
- Мультитаблица (несколько Sheet на проект).
- PWA / мобильное приложение.

### 5.3 Вне MVP (явно не входит)

- Полный кастомный CRUD UI (решение v1.3).
- Публичный CDN-реестр.
- Собственная БД для поручений.
- Промежуточные экраны превью / подтверждения.

## 6. Функциональные требования

### 6.1 Инициализация реестра

**По умолчанию (авто-создание):**

- При первом запуске BL-6 приложение создаёт **новую Google-таблицу** по шаблону PMI Action Item Tracker (заголовки A1:K1, форматирование).
- Пользователь сразу попадает на единый экран с пустой таблицей и smart-input.
- URL созданной таблицы сохраняется в конфигурации проекта.

**Подключение своего реестра (опционально):**

- В сайдбаре — пункт «Подключить свой реестр».
- Пользователь вводит URL существующей Google-таблицы.
- Приложение проверяет доступ и структуру колонок (A1:K1 по шаблону).
- При успешном подключении — автосозданная таблица удаляется; данные из пользовательской таблицы отображаются в реестре.

### 6.2 Единый экран

Один экран = весь инструмент. Никаких переходов между страницами.

**Сайдбар (левая панель):**

- «Реестр поручений» (активный пункт).
- «Открыть в Google Sheets ↗» — внешняя ссылка на исходную таблицу.
- Разделитель.
- «Подключить свой реестр» — опциональная замена авто-таблицы.
- «Настройки».

**Smart-input (верхняя часть):**

- Одно текстовое поле на всю ширину. Placeholder: *«Введите поручение или загрузите протокол / запись совещания…»*.
- Три кнопки справа:
  - 🎤 **Микрофон** — диктовка (Web Speech API или аналог); голос конвертируется в текст → далее как обычный текстовый ввод.
  - 📎 **Скрепка** — загрузка файла (аудио/видео протокола или записи совещания).
  - ➤ **Отправить** — запуск LLM-разбора текста.
- Пользователь вводит поручение свободным текстом и нажимает Enter / ➤.

**Таблица реестра (основная часть):**

- Данные из Google Sheet (через Sheets API `spreadsheets.values.get`).
- Обновление: при открытии страницы, после каждого сохранения (✓), по кнопке refresh.
- **Заголовки колонок с фильтрами ▾** (Excel-стиль): ID ▾ | Краткое название ▾ | Описание ▾ | Ответственный ▾ | Приоритет ▾ | Целевая дата ▾ | Статус ▾. Клик на ▾ — выпадающий фильтр по значениям колонки. Клик на название — сортировка.
- Редактирование существующих строк — только через Google Sheets (ссылка в сайдбаре).

### 6.3 Smart-input: текст → direct-to-table

**Flow:**

1. Пользователь вводит текст: *«Петров — подготовить ТЗ авторизации к 3 июня, важно, обсуждали на летучке»*.
2. Нажимает Enter / ➤.
3. Текст отправляется в LLM с промптом slot-filling: извлечь поля PMI.
4. LLM возвращает: `Brief Name`, `Description`, `Source`, `Owner`, `Priority`, `Target Date`.
5. Автозаполнение: `ID` = max + 1, `Date Added` = сегодня, `Status` = «1-Not started».
6. **Новая строка появляется в верхней части таблицы** в **edit-mode**:
   - Подсветка строки (жёлтый/amber фон).
   - Все ячейки — редактируемые текстовые поля.
   - Справа — кнопка **✓** (сохранить) и кнопка **✗** (удалить).
7. Поля, которые LLM не смог извлечь, остаются пустыми (пользователь заполнит вручную или оставит пустыми).

**Действия пользователя:**

- **✓ Сохранить** — строка записывается в Google Sheet через `spreadsheets.values.append`; edit-mode снимается, строка становится обычной read-only.
- **✗ Удалить** — строка исчезает из таблицы; в Google Sheet ничего не записывается.
- **Правка полей** — пользователь может исправить любое поле перед сохранением.

**Диктовка (🎤):**

- Нажатие на 🎤 активирует запись голоса (Web Speech API).
- Голос конвертируется в текст, который подставляется в поле smart-input.
- Далее — тот же flow, что и при текстовом вводе (Enter → LLM → строка в таблице).

### 6.4 AI-инжест файла: 📎 → direct-to-table

**Flow:**

1. Пользователь нажимает 📎 → диалог выбора файла.
2. Принимаются: аудио (`.mp3`, `.m4a`, `.ogg`, `.wav`, `.opus`), видео (`.mp4`, `.mov`, `.webm`, `.mkv`), ≤ 500 МБ.
3. Файл загружается → tmp.
4. Видео → ffmpeg → аудиодорожка; аудио — напрямую.
5. SaluteSpeech STT → транскрипт.
6. Удалить медиафайл немедленно.
7. LLM: разбить транскрипт на отдельные поручения; для каждого извлечь поля PMI.
8. `Source` — автоматически (формат: «Совещание <имя файла>, <дата>»).
9. **N новых строк появляются в верхней части таблицы** в edit-mode (каждая с ✓ / ✗).

**Действия пользователя:**

- Для каждой строки независимо: **✓** сохранить или **✗** удалить.
- Правка полей перед сохранением.
- Кнопка «✓ Сохранить все» (batch) — опционально, если строк много.

**Прогресс:**

- Во время обработки (загрузка → STT → LLM) в области smart-input отображается прогресс-бар / spinner с текстом этапа: «Транскрипция…», «Извлечение поручений…».
- Для файлов > 25 МБ — асинхронная обработка; статус через polling.

**Обработка ошибок:**

| Ситуация | Реакция |
|----------|---------|
| Файл > 500 МБ | Отказ до загрузки с подсказкой |
| Неподдерживаемый формат | Отказ с перечнем допустимых |
| SaluteSpeech недоступен | Сообщение в области smart-input; retry |
| LLM не извлёк поручения | Сообщение «Не удалось извлечь поручения»; пустая строка в edit-mode для ручного заполнения |
| Google Sheets API ошибка | Сообщение с деталями; retry |

### 6.5 Telegram-инжест (BL2-2)

- Telegram-бот принимает: текст, голос, аудио, видео.
- **Текст** → LLM → 1 строка.
- **Голос/аудио/видео** → SaluteSpeech STT → LLM → строка(и).
- Эвристика совещание vs одиночное поручение (ключевые слова, duration ≥ 90 с, файл ≥ 3 МБ).
- Результат: бот отвечает в тред: «Извлечено N поручений — подтвердите в веб-интерфейсе: <ссылка>».
- При переходе по ссылке — на едином экране появляются строки в edit-mode (✓ / ✗).
- Файлы из Telegram > 25 МБ → подсказка использовать веб-загрузку.

### 6.6 Данные и конфиденциальность

- В LLM — только текст ввода / нормализованный транскрипт.
- Медиафайлы не хранятся (tmp → STT → удалить).
- Google Sheet — ответственность пользователя за sharing и PII.

## 8. Контракт API (логический, MVP)

### Инициализация реестра

```
POST /api/projects/:projectId/sheets/init
     → { spreadsheet_url: string, spreadsheet_id: string }
     Создаёт новую Google-таблицу по шаблону PMI.

POST /api/projects/:projectId/sheets/connect
     Body: { spreadsheet_url: string }
     → { ok: true, sheet_title: string, row_count: number }
     Подключает существующую таблицу; удаляет автосозданную.

GET  /api/projects/:projectId/sheets/status
     → { connected: boolean, spreadsheet_url?, spreadsheet_id? }
```

### Реестр (read-only из Sheet)

```

     → { data: Row[], meta: { total: number, spreadsheet_url: string } }
```

### Фаза BL2-0 — Единый экран + Google Sheets + smart-input + AI-инжест файлов

**phase_id:** BL2-0  
**status:** `planned`  
**Зависит от:** —

**Цель:** полностью рабочий инструмент на одном экране: авто-создание таблицы, smart-input с LLM, загрузка файлов с STT+LLM, direct-to-table.

**Scope:**

- Google Sheets API: авторизация, создание таблицы по шаблону, чтение, запись, batch-запись.
- Endpoints: `/sheets/init`, `/sheets/connect`, `/sheets/status`, `/assignments` (GET/POST), `/assignments/parse`, `/assignments/batch`, `/ingest` (POST/GET).
- Web UI — единый экран (§6.2):
  - Сайдбар (навигация, «Открыть в Google Sheets ↗», «Подключить свой реестр»).
  - Smart-input (текстовое поле + 🎤 + 📎 + ➤).
  - Таблица реестра (Excel-стиль фильтры ▾ в заголовках).
  - Edit-mode строки (подсветка, editable fields, ✓ / ✗).
  - Прогресс-бар для обработки файлов.
- LLM slot-filling: промпт для разбора свободного текста и транскриптов.
- STT pipeline: SaluteSpeech + ffmpeg для видео.
- Диктовка: Web Speech API (клиентская).

**Env:** `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`, `GOOGLE_REDIRECT_URI` (OAuth 2.0); LLM API key; `SALUTESPEECH_CLIENT_ID`, `SALUTESPEECH_SECRET`. Токены пользователя — только в сессии/хранилище приложения, не в env репозитория.

**Критерий готовности:**

- При первом запуске — авто-создание таблицы, сразу на рабочем экране.
- Текстовый ввод → LLM → строка в edit-mode → ✓ → строка в Google Sheet.
- Минимальный ввод («обновить документацию») → Brief Name заполнен, остальное пусто → ✓ → запись.
- 📎 mp3 → STT → LLM → N строк в edit-mode → ✓ на каждой → N строк в Sheet.
- 📎 mp4 → ffmpeg → тот же pipeline.
- ✗ → строка исчезает, в Sheet ничего.
- Файл > 500 МБ → отказ.
- Excel-фильтры ▾ работают.
- «Открыть в Google Sheets ↗» в сайдбаре → корректная ссылка.
- «Подключить свой реестр» → автосозданная таблица заменяется.

**phase_id:** BL2-1  
**status:** `planned`

**Цель:** альтернативный канал ввода через Telegram; базовые напоминания.

## 10. Последовательность и зависимости

```
BL2-0 (единый экран + Sheets + smart-input + AI-инжест файлов) ← ВСЯ ЦЕННОСТЬ
  └─► BL2-1 (Telegram + напоминания) — опциональное расширение
```

**Одна фаза до полной ценности.** BL2-0 включает и текстовый ввод с LLM, и загрузку файлов с STT — оба сценария на одном экране. Отдельная фаза для файлового инжеста больше не нужна, потому что нет отдельного UI (экрана подтверждения).

**BL2-1** — расширение: Telegram и напоминания для команд, уже использующих Telegram.
