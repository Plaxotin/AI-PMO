# План реализации BL-1 «Аудит проектного плана» (по спецификации v0.2.2)

**Дата:** 20.07.2026 · **Статус:** к утверждению · **Трудоёмкость:** 16–24 ч/д (один фулстек-разработчик, 4 недели; двое — ~2,5–3 недели)

## 0. Рамка

**В скоупе MVP:** загрузка .xlsx/.xls/.csv/.xml(MSPDI)/.mpp; 4 режима анализа; CPM алгоритмический; **движок соответствия Инструкции (R-01…R-12)**; LLM-анализ (**только Kimi/Moonshot в beta**, абстракция `lib/llm.ts`); отчёт + **диаграммы D-01…D-04 по шаблонам Инструкции** + PDF; деидентификация ПДн (2 контура); freemium-лимит 3 анализа/день; демо-файл.
**Вне скоупа:** платежи (fast-follow), регистрация (v0.3), Google Sheets, master-проекты MPP, загрузка своей инструкции (v0.3).

**Предусловия (неделя 0, 1–2 ч/д, владелец — PM):**
- [ ] Репозиторий `github.com/Plaxotin/AI-PMO`, Vercel-проект, автодеплой из main
- [ ] **Kimi API key (Moonshot)**; аккаунт Yandex Cloud (для конвертера)
- [ ] Тестовый корпус: `для теста - План_график_АСУП...xlsx` + его экспорт в .xml и .mpp; ещё ≥ 8 реальных .mpp (корпус для AC-14)
- [ ] Эталон разметки нарушений R-01…R-12 по тестовому плану (для AC-18)
- [ ] Демо-файл `sample-plan.xlsx` (без реальных ПДн)
