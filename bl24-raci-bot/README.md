# BL-24 «Генератор RACI» — Telegram-бот

Telegram-агент для пользователей РФ: по свободному описанию проекта генерирует
RACI-матрицу по методологии **PMBOK** и присылает результат в **Excel (.xlsx)**.
Аналог агента RACI Chart Creator из PMI Infinity, адаптированный под РФ
(русский язык, роли вместо ФИО, LLM — Kimi/Moonshot, предупреждение 152-ФЗ).

## Состав

| Файл | Назначение |
|---|---|
| `bot.py` | Telegram-бот (aiogram 3, FSM-диалог) |
| `raci_engine.py` | Промпт по PMBOK, генерация через Kimi, валидация правил RACI |
| `kimi_client.py` | Клиент Moonshot API (stdlib, без внешних зависимостей) |
| `xlsx_builder.py` | Формирование Excel: матрица, легенда R/A/C/I, примечания |
| `demo.py` | Офлайн-прогон без LLM: демо-матрица → `demo_output/raci_demo.xlsx` |
| `SPEC.md` | Спецификация фичи BL-24 |

## Диалог с ботом

1. `/start` — приветствие + предупреждение о конфиденциальности (152-ФЗ: только роли, без ФИО).
2. Пользователь присылает описание проекта (до 4000 символов).
3. Бот показывает сводку: **«✅ Генерировать / ✏️ Уточнить»**.
4. Выбор режима: **«⚡ Быстрее»** или **«📋 С рекомендациями»** (подробные notes).
5. Бот генерирует матрицу (Kimi), валидирует правила PMBOK, присылает `.xlsx`.

## Запуск

```bash
pip install -r requirements.txt

# Windows (cmd)
set BOT_TOKEN=123456:ABC...        # токен от @BotFather
set KIMI_API_KEY=sk-...            # ключ Moonshot
python bot.py
```

Переменные окружения:
- `BOT_TOKEN` — обязателен.
- `KIMI_API_KEY` — без него бот отвечает демо-матрицей (пример внедрения MES).
- `KIMI_BASE_URL` — по умолчанию `https://api.moonshot.cn/v1`.
- `KIMI_MODEL` — по умолчанию `moonshot-v1-8k`.

## Проверка без Telegram и без LLM

```bash
python demo.py
```

Создаёт `demo_output/raci_demo.xlsx` и печатает результат валидации PMBOK
(ровно один A и минимум один R на активность, допустимые буквы и роли).
