# Спецификация BL-24 «Генератор RACI» (Telegram-агент)

**Статус:** драфт к реализации · **Приоритет:** quick win · **Риск-метка (152-ФЗ):** низкий — вход: свободный текст описания проекта без ПДн; выход: файл Excel. Обработка ПДн исключена дизайном (роли вместо ФИО + предупреждение в /start).

## Цель

Дать российскому руководителю проектов RACI-матрицу по PMBOK за 2–3 минуты —
аналог агента **RACI Chart Creator** из PMI Infinity, но с результатом в **Excel** и адаптацией под РФ.

## Референсы

- PMI Infinity, агент «RACI Chart Creator» (скрины диалога и docx-образец в `референсы и теория стартапа/PMI Infinity/RACI Creator/`).
- Методология: PMBOK (PMI), матрица ответственности R/A/C/I; статья pmi.org/blog/stakeholder-management-raci.

## Функциональные требования

| № | Требование |
|---|---|
| FR-1 | Вход: свободное текстовое описание проекта (цель, работы, роли, фазы), до 4000 символов |
| FR-2 | Подтверждение понимания: сводка описания + кнопки «Генерировать / Уточнить» |
| FR-3 | Два режима генерации: «Быстрее» и «С рекомендациями» (расширенные notes) |
| FR-4 | Генерация через **Kimi (Moonshot)** — единственная LLM в beta; строгий JSON-ответ |
| FR-5 | Валидация правил PMBOK: ровно один A и ≥1 R на активность; буквы только R/A/C/I; роли из списка; при нарушении — один repair-запрос |
| FR-6 | Выход: `.xlsx` — метаданные проекта, матрица «активности × роли» (A подсвечены), легенда R/A/C/I, примечания/допущения |
| FR-7 | Демо-режим без API-ключа (встроенный пример внедрения MES) |

## Нефункциональные требования

- **152-ФЗ / конфиденциальность:** предупреждение в /start; роли вместо ФИО; описание не хранится (только FSM-сессия); логи без текста описаний.
- **Стек:** Python, aiogram 3, openpyxl; LLM-клиент на stdlib (без openai-sdk).
- **Лимиты:** 8–20 активностей, 4–12 ролей (соответствует образцу PMI: 18 × 11).

## UX-флоу (по скринам PMI Infinity)

1. `/start` → приветствие + предупреждение 152-ФЗ.
2. Описание проекта → сводка → «✅ Генерировать / ✏️ Уточнить».
3. «⚡ Быстрее / 📋 С рекомендациями».
4. Генерация → валидация → отправка `.xlsx` с caption (активностей/ролей) → готов к новому описанию.

## Формат Excel (по образцу PMI docx)

- Заголовок, блок метаданных (название / цель / содержание / «сформировано AI PMO»).
- Матрица: колонка «Фаза · Активность» + колонки ролей; первые строки каждой фазы подсвечены; ячейки **A** — акцентная заливка; закрепление шапки.
- Легенда R/A/C/I (формулировки PMBOK на русском).
- Примечания и допущения (3–8 пунктов, как в образце PMI).
