# Реестр поручений (Task Registry)

Скилл для ведения реестра деловых поручений в Google Таблицах с автоматическими напоминаниями в Telegram.

## Структура реестра

Google Таблица содержит лист "Поручения" со следующими столбцами:

| Столбец | Название | Описание |
|---------|----------|----------|
| A | ID | Автоинкрементный номер поручения |
| B | Дата создания | Дата постановки поручения (DD.MM.YYYY) |
| C | Автор/Источник | Кто поставил поручение |
| D | Контрагент | Компания/контрагент, к которому относится задача |
| E | Описание | Текст поручения |
| F | Ответственный | ФИО ответственного |
| G | Срок | Плановая дата выполнения (DD.MM.YYYY) |
| H | Статус | Новое / В работе / На проверке / Выполнено / Отменено / Просрочено |
| I | Дата закрытия | Дата фактического закрытия (DD.MM.YYYY) |
| J | Комментарий | Примечания |

## Статусы поручений

- **Новое** — только создано, не взято в работу
- **В работе** — активно выполняется
- **На проверке** — выполнено, требует проверки
- **Выполнено** — закрыто успешно
- **Отменено** — отменено автором
- **Просрочено** — срок истёк, статус не "Выполнено" или "Отменено"

## Быстрый старт

### Первоначальная настройка (выполнить один раз)

1. **Google Sheets API** — запусти `scripts/setup_gsheets.py` и следуй инструкциям
2. **Telegram-бот** — запусти `scripts/setup_telegram.py` и следуй инструкциям
3. **Создание реестра** — запусти `scripts/task_manager.py --init`

### Ежедневная проверка сроков

Запусти `scripts/task_manager.py --check-deadlines` для:
- Проверки просроченных поручений (автоматическая смена статуса на "Просрочено")
- Отправки напоминаний о поручениях со сроком сегодня или завтра

## Основные команды

### Добавить поручение

```bash
python scripts/task_manager.py --add \
  --author "Иванов И.И." \
  --project "Альфа" \
  --description "Подготовить презентацию" \
  --assignee "Петров П.П." \
  --deadline "15.07.2026"
```

### Список поручений

```bash
# Все активные (не закрытые)
python scripts/task_manager.py --list --status "Новое,В работе,На проверке"

# По контрагенту
python scripts/task_manager.py --list --project "Альфа"

# По ответственному
python scripts/task_manager.py --list --assignee "Петров П.П."

# Просроченные
python scripts/task_manager.py --list --status "Просрочено"
```

### Изменить статус

```bash
python scripts/task_manager.py --update <ID> --status "В работе"
```

### Проверить сроки и отправить напоминания

```bash
python scripts/task_manager.py --check-deadlines
```

## Настройка cron для автоматических напоминаний

Настрой cron-задание для ежедневной проверки сроков:

```bash
# Каждый день в 9:00 утра
openclaw cron add --name "task-deadlines" --schedule "0 9 * * *" --command "python scripts/task_manager.py --check-deadlines"
```

## Работа через Telegram-бота

После настройки Telegram-канала в OpenClaw можно управлять поручениями прямо из Telegram.

### Доступные команды

**Добавить поручение (через команду):**
```
/add контрагент "Альфа" описание "Подготовить отчёт" ответственный "Иванов" срок 20.07.2026
```

**Добавить поручение (естественный язык):**
```
Добавь поручение: контрагент Альфа, подготовить отчёт, Иванов, до 20 июля
```

**Список поручений:**
```
/list
```

**Справка:**
```
/help
```

### Голосовые сообщения

Отправь голосовое сообщение — бот распознает текст через **Yandex SpeechKit** и создаст поручение.

Ключ Yandex API уже настроен в конфиге OpenClaw (`env.vars.YANDEX_API_KEY`).

**Как работает:**
1. Голосовое сообщение скачивается из Telegram
2. Отправляется на распознавание в Yandex SpeechKit STT
3. Распознанный текст парсится как обычное текстовое поручение
4. Бот сообщает результат: что распознал и какое поручение создал

### Поддерживаемые форматы дат

- `20.07.2026` — полная дата
- `20.07` — сокращённая (текущий год)
- `сегодня`, `завтра`, `послезавтра` — относительные
- `20 июля`, `15 марта` — с названием месяца

## Требования

- Python 3.8+
- Библиотеки: `gspread`, `google-auth`, `requests`
- Учётная запись Google с доступом к Google Sheets
- Telegram-бот (получить через @BotFather)
- Yandex API ключ (SpeechKit для голосовых сообщений)
